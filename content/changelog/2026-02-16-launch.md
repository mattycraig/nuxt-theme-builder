The Theme Builder launched with everything you need to design a Nuxt UI v4 theme without guessing:

- Semantic colors, shades, neutral, radius, and font, set separately for light and dark mode.
- Live previews across components, blocks, and full page templates.
- Built-in presets to start from, plus undo and redo and saved themes.
- AI theme generation using your own API key.
- Export as `app.config.ts`, CSS, or JSON.
- Color tools and a Learning Hub with guides on theming Nuxt UI.
