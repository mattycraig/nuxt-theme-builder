The new [Docs](/templates/docs) template shows a documentation site for a made-up UI library, open on its installation guide. It has grouped sidebar navigation, search, install tabs for each package manager, code blocks, callouts, an options table, and previous and next page cards. The "On this page" list on the right follows you as you scroll.

Long-form text is where a font choice shows its strengths and weaknesses, so this is a good page for judging your font, muted text, and primary links together.
