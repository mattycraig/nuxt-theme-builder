The **Nuxt UI** preset used Tailwind's green, which is close to Nuxt's brand green but not the same. It now uses the Nuxt green (`#00DC82`) for primary and success. Dark mode was also rendering every semantic color one step too light, and now matches what a fresh Nuxt UI project looks like.
