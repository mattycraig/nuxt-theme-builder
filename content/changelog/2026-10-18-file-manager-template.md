The new [File Manager](/templates/file-manager) template is a cloud drive. The sidebar has a folder tree and a storage meter, and the main area shows quick access files, folders, and files in a grid or a list. Right-click a file for its menu, select one to see its details and who has access, or open the upload dialog.

It's the only template that uses the Tree and Context Menu components.
